# Titre:

Stellarium

# Contexte : 

Pour conclure une semaine d'apprentissage sur L'HTML et le CSS on devait réaliser un jeu d'aventure à choix multiple à thème libre avec un minimum de 10 pages.

# Pré-requis :

Aucun prérequis nécessaire.

#Guide d'installation et d'utilisation.

A partir du fichier Stellarium que vous avez téléchargé, lancez "index.html"
